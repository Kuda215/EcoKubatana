# 🚀 Quick Start - Run These Commands in Order

# STEP 1: Install Supabase
npm install @supabase/supabase-js

# STEP 2: Create .env file (copy from .env.example and add your keys)
# Windows PowerShell:
Copy-Item .env.example .env

# Then edit .env and paste your Supabase URL and ANON KEY

# STEP 3: Set up database (Go to Supabase Dashboard → SQL Editor and run the SQL from SETUP_GUIDE.md)

# STEP 4: Start the app
npm run dev

# STEP 5: Test
# - Open browser to http://localhost:5173
# - Click "Create Account"
# - Select a role and register
# - Check Supabase Dashboard → Authentication → Users to see your new user

# ✅ All Done!
